# Admin Module

## 1- POST /api/v1/admin/visit

|                    |                             |
| ------------------ | --------------------------- |
| **Description**    | Create a new patient visit  |
| **Method**         | `POST`                      |
| **Endpoint**       | `/api/v1/admin/visit`       |
| **Content-Type**   | multipart/form-data         |
| **Authentication** | Required (Cookie-based JWT) |
| **Authorization**  | Admin                       |

### Request Body

```typescript
{
  patientId: string; // Patient global id (UUID)
  diagnoses: string; // Optional if audio is provided, otherwise required
  audio: File; // Optional (mp3, mpeg, ogg, wav) | Max Size = 10 MB
}
```

### Response (201 - Success)

## 5- GET /api/v1/admin/patient/:id/visits

|                    |                                    |
| ------------------ | ---------------------------------- |
| **Description**    | Get all visits for a patient       |
| **Method**         | `GET`                              |
| **Endpoint**       | `/api/v1/admin/patient/:id/visits` |
| **Content-Type**   | application/json                   |
| **Authentication** | Required (Cookie-based JWT)        |
| **Authorization**  | Admin                              |

### Path Parameters

| Parameter | Type | Description              |
| --------- | ---- | ------------------------ |
| `id`      | UUID | Patient global id (UUID) |

### Response (200 - Success)

```typescript
{
  patient: {
    id: string;
    name: string;
    gender: Gender; // 0 = MALE, 1 = FEMALE
    dateOfBirth: string; // ISO date string
    socialSecurityNumber: string;
    address: string | null;
    job: string | null;
  }
  clinics: {
    id: string;
    name: string;
    visits: {
      doctor: {
        name: string;
        speciality: string;
      }
      diagnosesAudioUrl: string | null;
      diagnoses: string;
      createdAt: string; // ISO date string
    }
    [];
  }
  [];
}
```
