╠══════════════════════════════════════════════════════════════════╣
║                                                                  ║
║  • SessionInitializer (components/shared/SessionInitializer.tsx) ║
║    → Auto-mounts in Providers                                    ║
║    → Runs on every page load/refresh                             ║
║                                                                  ║
║  • useSessionValidation (hooks/useSessionValidation.ts)          ║
║    → Validates HTTP-only cookie                                  ║
║    → Caches results for 30 seconds                              ║
║    → Returns: isValidating, isAuthenticated, error               ║
║                                                                  ║
║  • useSessionCache (hooks/useSessionCache.ts)                    ║
║    → In-memory cache for session validation                      ║
║    → Configurable duration (default: 30s)                        ║
║                                                                  ║
║  • AuthGuard (components/shared/AuthGuard.tsx)                   ║
║    → Enhanced to use session validation                          ║
║    → Shows loading while validating                              ║
║    → Only redirects after validation completes                    ║
